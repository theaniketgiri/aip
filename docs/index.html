The Problem

Every AI framework lets agents do things. None of them verify what agents are allowed to do.

🎭

No Identity

Agents have no cryptographic identity. There's no mathematical proof of which agent is performing an action. Any agent can impersonate any other.

🔓

No Boundaries

A LangChain agent can drain a bank account. A CrewAI agent can delete production data. There's no protocol-level enforcement of what an agent is allowed to do.

💀

No Kill Switch

If an agent goes rogue — prompt injection, hallucination, or exploit — there is no way to instantly revoke its access across all tools and systems in real-time.

AIP Fixes This

One protocol. Every agent. Cryptographic proof before every action.

Identity

Agent Passports

Ed25519 keypair per agent with DID-based addressing. Identity is mathematical, not prompt-based. Tamper-proof and auditable.

Verification

Signed Intent Envelopes

Before every action, the agent signs: "I am X, doing Y, at time T." The receiving system verifies the signature cryptographically.

Boundaries

The Cage

Action allowlists, deny lists, monetary limits per transaction, geo restrictions. Enforced deterministically at the protocol layer.

Kill Switch

Instant Revocation

Revoke any agent globally with zero propagation delay. Once revoked, every tool call fails verification. Sub-millisecond. No network.

Trust

Bayesian Trust Scores

Trust is earned over successful verifications. New agents start untrusted. Anomalous behavior degrades trust automatically.

Detection

Intent Drift

Semantic classifier flags actions outside an agent's declared scope. Catches subtle boundary violations that rule systems miss.

Quick Start

Protect your first agent in 30 seconds.

quickstart.py 
from aip_protocol import AgentPassport, create_envelope, sign_envelope, verify_intent
from aip_protocol.revocation import RevocationStore

# 1 — Create an agent passport (identity + keys + boundaries)
passport = AgentPassport.create(
    domain="yourco.com",
    agent_name="procurement-bot",
    allowed_actions=["read_invoice", "transfer_funds"],
    monetary_limit_per_txn=50.0,
)

# 2 — Agent declares intent before acting
envelope = create_envelope(
    passport, action="transfer_funds",
    target="did:web:vendor.com",
    parameters={"amount": 45.00},
)
signed = sign_envelope(envelope, passport.private_key)

# 3 — Verify through the 8-step pipeline
store = RevocationStore()
result = verify_intent(signed, passport.public_key, revocation_store=store)

if result.passed:
    print(f"✓ Verified — tier: {result.tier_used.value}")
else:
    print(f"✗ Blocked — {result.errors}")
    # → "✗ AIP-E202: MONETARY_LIMIT"

Works With Any Framework

AIP is framework-agnostic. One decorator protects any tool.

🦜 LangChain 👥 CrewAI 🔷 Google ADK 🤖 AutoGen 🐍 Any Python
one_liner.py 
from aip_protocol import shield

# One decorator. Any function. Cryptographic verification.
@shield(passport, allowed_actions=["transfer_funds"], monetary_limit=500.0)
def send_payment(to: str, amount: float):
    bank.transfer(to, amount)

send_payment("vendor@acme.com", 45.00)   # ✓ Verified
send_payment("vendor@acme.com", 500.00)  # ✗ AIP-E202: MONETARY_LIMIT
